# DreamService V1.0 — public contact, links, and external references audit

Audit date: 2026-10-29. Stage 1 only. No replacement values have been approved.

## Scope and limits

Inspected the current working tree, including existing uncommitted work: `src`, root `messages/en.json` and `messages/fa.json`, `i18n`, `public`, Prisma schema/migrations, scripts, root configuration, `.env.example`, README, and engineering/deployment documentation. There is no `src/config` directory or Prisma seed script in this tree. Git's configured remote was inspected separately as repository metadata.

Excluded dependency directories, generated builds, Git internals as application content, coverage/test artifacts, database backups, and actual environment files. No database was queried; no customer records or live credentials were read. Configuration names below come from source and examples, not live environment values. Dependency lockfile URLs were classified separately as installation/funding metadata.

Public SVGs were inspected for text, links, and external references. The avatar was visually inspected; raster assets were scanned for literal URL/email metadata. The PDF was inspected through its page tree, metadata, and embedded text/font mappings: 215 current pages, 214 with extractable text. This was not an OCR or full visual review; image-only text and fragmented text may contain additional references. Database-driven content, deployment-injected settings, external account ownership, and external URL reachability remain unverified. No external URLs were fetched.

**CONFIRM** = potentially valid or missing release information requiring an owner decision. **REPLACE** = placeholder or suspicious release content. **KEEP** = intentional internal/development reference or valid interface example. **REMOVE?** = removal is a proposal requiring approval. Every recommendation is pending; this report is the only file created by Stage 1.

Locations are repository-relative `file:line`; PDF locations use physical page numbers. Both message catalogs have identical key sets: 633 keys each.
